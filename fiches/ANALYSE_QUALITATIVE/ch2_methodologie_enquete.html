Analyse Qualitative — M1

Méthodologie de l'enquête qualitative

1. Les 5 étapes
1. Choix du terrain → 2. Guide d'entretien → 3. Réalisation des entretiens → 4. Retranscription → 5. Analyse
2. Le guide d'entretien
Structuré selon la logique de l'entonnoir (général → spécifique).
Plan type : présentation du travail / du sujet / objectifs de publication / questions ouvertes ou fermées.
Le guide d'entretien va dans les ANNEXES du mémoire, PAS dans la méthodologie.
3. Réalisation des entretiens
CritèreRecommandation
Durée idéale45 minutes
Minimum exigé5 entretiens
FormatsFace à face, téléphone, visio
EnregistrementConseillé, avec accord de l'interviewé
Noms citésAutorisation écrite obligatoire
4. Retranscription
Transcription intégrale obligatoire.
Format : Entretien n°X – Fonction – Date – Durée – Lieu (anonymisé).
Numéroter les lignes pour le codage.
5. À ne pas oublier
Toute la démarche (approche, personnes interviewées, questions, méthode d'analyse) doit être décrite en DÉTAIL dans la section collecte des données.
Utiliser la revue de littérature comme toile de fond pour structurer le guide d'entretien.
6. Flash questions
Q : Quelle est la durée idéale d'un entretien qualitatif ?
45 minutes — pas trop long pour ne pas lasser l'interlocuteur.
Q : Combien d'entretiens minimum sont exigés ?
Minimum 5 entretiens.
Q : Où place-t-on le guide d'entretien dans le mémoire ?
Dans les ANNEXES, pas dans la partie méthodologie.
