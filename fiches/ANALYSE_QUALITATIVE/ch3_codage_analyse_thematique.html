Analyse Qualitative — M1

Codage & Analyse thématique

1. Le pipeline d'analyse
Pipeline complet : Données → Unités de sens → Codes → Catégories → Thèmes → Récit → Affirmations
2. Les 3 niveaux de codage
NiveauCe qu'on faitRésultat
Codage ouvertDécouper en unités de sens, étiquettes provisoiresCodes bruts proches des données
Codage axialRelier les codes (conditions, interactions, conséquences)Catégories et sous-catégories
Codage sélectifIdentifier LA catégorie centraleRécit cohérent (storyline)
3. Règles de codage
Noms de codes courts + descriptifs. Les verbes aident : « gérer le risque », « rejeter la faute ».
Codebook léger : nom du code + définition courte + 2-3 citations exemplaires.
Ne PAS ignorer les segments incertains → les mettre dans une liste « à vérifier ».
4. Construire des catégories
Bonnes catégories = conceptuellement claires (1 idée) + analytiquement utiles (expliquent quelque chose) + distinctes mais liées.
Test de validité : si on ne peut pas résumer la catégorie en 2-3 phrases sans lister les codes → continuer à fusionner/scinder.
5. Thèmes ≠ catégories
Un thème ≠ simple catégorie de sujet. Un thème capture un SENS PARTAGÉ unifié par un concept organisateur central.
Analyse verticale (intra-cas) = rester dans 1 entretien pour le contexte.
Analyse horizontale (inter-cas) = comparer entre entretiens.
6. Rédaction des résultats
Structure : Abstract → Introduction → Revue de littérature → Méthodologie → Résultats → Discussion → Conclusion → Annexes.
Équilibrer description (faire vivre les contextes) et interprétation (expliquer les motifs et le sens).
7. Flash questions
Q : Quel est le pipeline complet de l'analyse qualitative ?
Données → Unités de sens → Codes → Catégories → Thèmes → Récit → Affirmations.
Q : Quelle est la différence entre codage ouvert et codage axial ?
Ouvert = découper et étiqueter. Axial = relier les codes entre eux pour former des catégories.
Q : Un thème est-il la même chose qu'une catégorie ?
Non ! Un thème capture un SENS PARTAGÉ unifié par un concept central. Une catégorie est plus descriptive.
