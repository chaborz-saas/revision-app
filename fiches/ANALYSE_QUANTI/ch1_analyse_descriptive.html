Analyse de Donnees Quantitatives

Cours 1 — Analyse descriptive univariee (stats de base)

Definitions essentielles
Definition
Analyse descriptive univariee = etude d'une seule variable separement des autres. Objectif : comprendre la structure des donnees, degager des tendances, identifier anomalies et opportunites.
Principe fondamental
Le type de variable determine les outils statistiques utilisables. Une moyenne sur une variable qualitative nominale (ex : genre) n'a aucun sens.
Les 4 types de variables
TypeDefinitionIndicateursGraphiques
Quali. nominale Categories sans ordre Freq. absolue/relative, mode Circulaire, batons
Quali. ordinale Categories avec ordre Freq., mode, mediane Circulaire, batons
Quanti. discrete Nombres entiers Moyenne, mediane, ecart-type, variance, quartiles, etendue Histogramme, boxplot
Quanti. continue Valeurs reelles Moyenne, mediane, ecart-type, variance, quartiles, etendue Histogramme, boxplot
Indicateurs de tendance centrale
Formules
Moyenne (x̄) = ∑xi / n — sensible aux valeurs extremes
Mediane (Me) — valeur centrale : 50% au-dessus, 50% en dessous — plus robuste que la moyenne
Mode (Mo) — valeur la plus frequente — seul indicateur pour les variables qualitatives nominales
Astuce
Si mediane < moyenne : quelques valeurs elevees tirent la moyenne vers le haut (distribution asymetrique a droite).
Indicateurs de dispersion
Formules
Etendue (E) = Max - Min
Variance (σ²) = ∑(xi - x̄)² / n
Ecart-type (σ) = √(variance) — dispersion dans la meme unite que la variable
CV = (σ / x̄) × 100 — dispersion relative en %
Quartiles : Q1 (25%), Q2 = Mediane (50%), Q3 (75%)
A retenir
Forte dispersion = heterogeneite du groupe = a explorer managerialement.

4 pieges frequents
  • Confondre moyenne et mediane — Ex : salaire moyen 4 000 euros mais fortes inegalites
  • Oublier la dispersion — 2 groupes, meme moyenne, realites tres differentes
  • Se baser sur les valeurs extremes sans les identifier
  • Negliger la taille d'echantillon

Questions flash
Quelles sont les 4 familles de variables ? Qualitative nominale, qualitative ordinale, quantitative discrete, quantitative continue.
Quel est le seul indicateur de tendance centrale utilisable pour une variable qualitative nominale ? Le mode (valeur la plus frequente).
Quelle est la formule de la variance ? σ² = ∑(xi - x̄)² / n — moyenne des carres des ecarts a la moyenne.
Pourquoi la mediane est-elle plus robuste que la moyenne ? Parce qu'elle n'est pas influencee par les valeurs extremes. Si mediane < moyenne, quelques valeurs elevees tirent la moyenne vers le haut.
Quels indicateurs et graphiques pour une variable qualitative nominale ? Frequence absolue, frequence relative, mode. Graphiques : diagramme circulaire, diagramme en batons.
Quels indicateurs et graphiques pour une variable quantitative continue ? Moyenne, mediane, ecart-type, variance, min, max, quartiles, etendue. Graphiques : histogramme, boxplot.
Que signifie une forte dispersion dans les donnees ? Une heterogeneite du groupe, a explorer managerialement (ex : segmenter la clientele, identifier les profils extremes).
Quels sont les 4 types de mesure dans Jamovi ? Nominal, Ordinal, Continu, Identite.
