Logique du test d'hypothese
Schema universel
H0 = pas de relation (innocent) | H1 = relation existe (coupable)
p-value ≤ 0,05 → on rejette H0 (significatif) | p-value > 0,05 → on ne rejette pas H0
Le test t de Student (2 groupes)
  • Compare les moyennes de 2 groupes (1 quanti + 1 quali a 2 modalites)
  • H0 : μ1 = μ2 | H1 : μ1 ≠ μ2
Formule
t = (μ1 - μ2) / √(s1²/n1 + s2²/n2)
p-value = 2 × P(T ≥ |t|)
L'ANOVA : pourquoi et comment
Piege a eviter
Multiplier les tests t deux a deux → inflation du risque d'erreur. L'ANOVA resout ce probleme en un seul test global.
  • Question centrale : la variabilite vient-elle des groupes ou du hasard ?
  • Decomposition : Variance Totale = Variance Inter-groupes + Variance Intra-groupes
  • H0 : toutes les moyennes sont egales | H1 : au moins une moyenne differe
Formules ANOVA
Decomposition des sommes de carres
SCT = SCE + SCR

SCE (inter) = ∑ nj(&bar;Xj - &bar;X)2
SCR (intra) = ∑∑(Xij - &bar;Xj)2
SCT (totale) = ∑∑(Xij - &bar;X)2
Statistique F
F = (SCE / (k-1)) / (SCR / (N-k))
k = nombre de groupes, N = effectif total
Plus F est grand, plus l'effet est probable

Point cle
L'ANOVA dit s'il y a une difference, mais ne dit pas entre quels groupes. Il faut un test post-hoc (Tukey) pour identifier les paires.

Exercices types (examen)
Exercice type 1 : e-commerce
Panier moyen selon type de client (4 groupes) → F = 18,7 ; p < 0,001 → effet significatif. Tukey : tous les groupes different. Premium (68 €) = segment le plus strategique.
Exercice type 2 : performance RH
Performance selon service (5 groupes) → F = 9,85 ; p < 0,001 → effet significatif. IT (82) et Finance (78) se distinguent. Tukey : IT ≠ Marketing, RH, Ventes ; Finance ≠ RH.
Questions flash
Pourquoi ne pas multiplier les tests t au lieu de faire une ANOVA ? Multiplier les tests t entraine une inflation du risque d'erreur de type I. L'ANOVA permet un test global en une seule fois.
Quelle est la question centrale de l'ANOVA ? La variabilite observee est-elle due aux groupes (facteur etudie) ou simplement au hasard ?
Que faire si le test de Levene donne p ≤ 0,05 ? Les variances ne sont pas homogenes : il faut lire le test de Welch au lieu du test de Fisher classique.
L'ANOVA est significative (p < 0,05). Que faire ensuite ? Un test post-hoc (Tukey) pour identifier quelles paires de groupes different significativement, car l'ANOVA ne dit pas quels groupes different.
Donnez la formule de la statistique F. F = (SCE / (k-1)) / (SCR / (N-k)) = Variance inter-groupes / Variance intra-groupes. Plus F est grand, plus l'effet est probable.
Quelle est la difference entre ANOVA a un facteur et a deux facteurs ? Un facteur : 1 variable quali (3+ groupes). Deux facteurs : 2 variables quali, ce qui permet de tester 2 effets principaux + 1 effet d'interaction.
Que signifie SCT = SCE + SCR ? La variance totale (SCT) se decompose en variance expliquee par les groupes (SCE, inter) + variance residuelle a l'interieur des groupes (SCR, intra).
