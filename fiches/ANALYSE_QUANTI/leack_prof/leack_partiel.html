Analyse Quantitative — M1

Exercices corrigés — Résumé & Méthodes

1. Types de Variables
Qualitative nominale — Catégories SANS ordre. Ex : Genre, Ville
Qualitative ordinale — Catégories AVEC ordre. Ex : Satisfaction (faible / moyen / fort)
Quantitative discrète — Valeurs entières. Ex : Nombre de commandes
Quantitative continue — Valeurs réelles. Ex : Salaire, Chiffre d'affaires
2. Statistiques Descriptives
Tendance centrale
Moyenne = somme / n — sensible aux valeurs extrêmes
Médiane = valeur centrale — robuste aux outliers
Mode = valeur la plus fréquente
Distribution symétrique => Moyenne = Médiane = Mode
Dispersion
Étendue = Max − Min
Écart-type σ = √(variance)
CV = σ / moyenne × 100% — dispersion relative (comparaison entre groupes)
IQR = Q3 − Q1 — robuste aux outliers
Si des valeurs extrêmes sont présentes, la médiane est plus représentative que la moyenne.

5. Corrélation de Pearson
r compris entre −1 et +1
|r| 0–0.20 : très faible  |  0.20–0.40 : faible  |  0.40–0.60 : modérée  |  0.60–0.80 : forte  |  0.80–1.00 : très forte

H0 : r = 0  /  H1 : r ≠ 0  /  Décision : si p ≤ 0.05 => H0 rejetée
Significatif ≠ Fort. Ex : r = 0.16 avec p < 0.05 = significatif mais TRÈS faible — aucune pertinence managériale réelle.
6. ANOVA
H0 : toutes les moyennes sont égales  /  H1 : au moins une est différente
Variances homogènes (test de Levene) => utiliser Fisher
Variances hétérogènes => utiliser Welch
L'ANOVA dit S'IL y a une différence. Le test de Tukey dit LAQUELLE. Le post hoc Tukey est obligatoire pour identifier les groupes qui diffèrent.
7. Régression Linéaire Multiple
R² : % de variance expliquée. Ex : R² = 0.724 → 72,4% de la variance expliquée
R² ajusté : à préférer pour comparer des modèles (corrigé pour le nb de variables)
Test F : H0 = tous coeff = 0. Si p < 0.05 => modèle globalement significatif
β standardisé : permet de comparer l'influence RELATIVE des prédicteurs
Variables qualitatives : un niveau de référence ; le coefficient = différence vs référence
Un coefficient B élevé ne signifie pas une influence plus grande si les unités diffèrent. Toujours comparer via β standardisé.
8. Exercices du Partiel 2025/2026
Exercice 1
FeelWell — Analyse d'un histogramme de satisfaction
Une application de bien-être (FeelWell) dispose de données de satisfaction de 480 utilisateurs sur une échelle de 1 à 10. L'histogramme montre une distribution avec un pic centré sur les scores 5–6, des valeurs qui s'étendent de 4 à 7, et un petit groupe avec des notes très faibles (1–2).

Questions :
a) Décrivez la forme de cette distribution.
b) Quelle mesure de tendance centrale est la plus appropriée ? Pourquoi ?
c) Quel est le risque d'utiliser la moyenne ici ?
a) Forme : Distribution unimodale, globalement symétrique, pic centré sur 5–6, dispersion modérée (4–7).

b) Mesure appropriée : Dans une distribution symétrique, Moyenne = Médiane = Mode, donc les trois sont équivalentes. Cependant, à cause du petit groupe avec notes très faibles...

c) Risque : Le petit groupe de notes très faibles (1–2) tire la moyenne vers le bas, la rendant moins représentative. Préférer la médiane, plus robuste aux valeurs extrêmes.
Exercice 2
FeelWell — Interprétation d'une matrice de corrélation
La matrice de corrélation de FeelWell présente 5 variables : Satisfaction, Engagement, Utilisation (temps/semaine), Dépenses (€/mois) et Niveau de stress.

Résultats clés :
Engagement / Dépenses : r = 0.68**  |  Utilisation / Dépenses : r = 0.62**
Satisfaction / Engagement : r = 0.63**  |  Stress / Satisfaction : r = −0.39**
Stress / Dépenses : r = 0.16*

Questions :
a) Identifiez les corrélations les plus importantes pour la stratégie de l'entreprise.
b) Commentez la corrélation Stress / Dépenses.
c) Quelle méthode complémentaire proposeriez-vous ?
a) Corrélations stratégiques :
• Engagement / Dépenses : r = 0.68** — forte, positive, significative → levier principal de revenus
• Utilisation / Dépenses : r = 0.62** — forte, positive → plus de temps = plus de dépenses
• Satisfaction / Engagement : r = 0.63** — forte, positive → satisfaits = plus engagés
• Stress / Satisfaction : r = −0.39** — négative → plus de stress = moins de satisfaction = moins de fidélité

b) Stress / Dépenses : r = 0.16* — PIÈGE CLASSIQUE : statistiquement significatif (p < 0.05) mais corrélation TRÈS faible. Aucune pertinence managériale réelle. Ne pas conclure que le stress génère des dépenses.

c) Méthode complémentaire : Régression linéaire multiple — pour isoler l'effet propre de chaque variable sur les dépenses en contrôlant les autres.
Exercice 3
Régression multiple — Dépenses de santé aux USA
Un modèle de régression linéaire multiple prédit les dépenses de santé annuelles (en $) aux USA à partir de 4 prédicteurs : Âge, Sexe, Nombre d'enfants, Tabagisme (fumeur/non-fumeur).

Résultats du modèle :
R² = 0.724  |  R² ajusté = 0.723  |  F = 873, p < 0.001

Coefficients :
Tabagisme (fumeur) : B = 23 836.9, β_std = 1.968, p < 0.001
Âge : B = 273.1, β_std = 0.520, p < 0.001
Nb enfants : B = 486.2, β_std = 0.121, p < 0.001
Sexe (homme) : B = 61.3, β_std = 0.004, p = 0.861

Questions :
a) Évaluez la qualité globale du modèle.
b) Quel prédicteur a la plus grande influence ? Comment le déterminer ?
c) Peut-on interpréter l'effet du sexe ? Pourquoi ?
a) Qualité du modèle : R² = 0.724 → le modèle explique 72,4% de la variance des dépenses. F = 873, p < 0.001 → modèle globalement significatif. Excellente qualité.

b) Prédicteur le plus influent : On compare les β standardisés (pas les B bruts, car les unités diffèrent). Tabagisme : β_std = 1.968 — de loin le plus élevé → c'est le prédicteur le plus influent. Être fumeur représente une augmentation de +23 837$ par an.

c) Effet du sexe : NON — variable NON significative. p = 0.861 >> 0.05 → on ne peut pas rejeter H0. Le sexe n'a pas d'effet significatif sur les dépenses de santé dans ce modèle. À exclure de l'interprétation.
Flash Questions Types
Quelle mesure utiliser quand la distribution est asymétrique ?
La médiane — robuste aux valeurs extrêmes. La moyenne est tirée vers la queue.
Comment identifier le prédicteur le plus influent en régression ?
Comparer les β standardisés (estimation standardisée). Le plus grand en valeur absolue = plus grande influence relative.
ANOVA significative : que faire ensuite ?
Obligatoirement un test post hoc de Tukey pour identifier quels groupes diffèrent entre eux.
r = 0.16, p = 0.03 — comment interpréter ?
Significatif mais TRÈS faible. Statiquement significatif (p < 0.05) mais la corrélation est négligeable — aucune conclusion managériale pertinente.
R² = 0.724 — que signifie ce chiffre ?
Le modèle explique 72,4% de la variance de la variable dépendante. C'est un excellent pouvoir explicatif.
