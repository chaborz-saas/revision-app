1. Types de Variables
Qualitative nominale — Catégories SANS ordre. Ex : Genre, Ville
Qualitative ordinale — Catégories AVEC ordre. Ex : Satisfaction (faible / moyen / fort)
Quantitative discrète — Valeurs entières. Ex : Nombre de commandes
Quantitative continue — Valeurs réelles. Ex : Salaire, Chiffre d'affaires
2. Statistiques Descriptives
Tendance centrale
Moyenne = somme / n — sensible aux valeurs extrêmes
Médiane = valeur centrale — robuste aux outliers
Mode = valeur la plus fréquente
Distribution symétrique => Moyenne = Médiane = Mode
Dispersion
Étendue = Max − Min
Écart-type σ = √(variance)
CV = σ / moyenne × 100% — dispersion relative (comparaison entre groupes)
IQR = Q3 − Q1 — robuste aux outliers
Si des valeurs extrêmes sont présentes, la médiane est plus représentative que la moyenne.

5. Corrélation de Pearson
r compris entre −1 et +1
|r| 0–0.20 : très faible  |  0.20–0.40 : faible  |  0.40–0.60 : modérée  |  0.60–0.80 : forte  |  0.80–1.00 : très forte

H0 : r = 0  /  H1 : r ≠ 0  /  Décision : si p ≤ 0.05 => H0 rejetée
Significatif ≠ Fort. Ex : r = 0.16 avec p < 0.05 = significatif mais TRÈS faible — aucune pertinence managériale réelle.
6. ANOVA
H0 : toutes les moyennes sont égales  /  H1 : au moins une est différente
Variances homogènes (test de Levene) => utiliser Fisher
Variances hétérogènes => utiliser Welch
L'ANOVA dit S'IL y a une différence. Le test de Tukey dit LAQUELLE. Le post hoc Tukey est obligatoire pour identifier les groupes qui diffèrent.
7. Régression Linéaire Multiple
R² : % de variance expliquée. Ex : R² = 0.724 → 72,4% de la variance expliquée
R² ajusté : à préférer pour comparer des modèles (corrigé pour le nb de variables)
Test F : H0 = tous coeff = 0. Si p < 0.05 => modèle globalement significatif
β standardisé : permet de comparer l'influence RELATIVE des prédicteurs
Variables qualitatives : un niveau de référence ; le coefficient = différence vs référence
Un coefficient B élevé ne signifie pas une influence plus grande si les unités diffèrent. Toujours comparer via β standardisé.
8. Exemples du Partiel à Connaître
Exo 1 — FeelWell : histogramme de satisfaction (480 users)
Distribution unimodale, symétrique, pic centré sur 5–6, dispersion modérée (4–7).
Distribution symétrique => Moyenne = Médiane = Mode.
Risque : un petit groupe avec notes très faibles tire la moyenne vers le bas => préférer la médiane.
Exo 2 — Matrice de corrélation FeelWell
Engagement / Dépenses : r = 0.68** — forte, positive, significative => levier de revenus
Utilisation / Dépenses : r = 0.62** — forte, positive => plus de temps = plus de dépenses
Satisfaction / Engagement : r = 0.63** — forte, positive => satisfaits = plus engagés
Stress / Satisfaction : r = −0.39** — négatif => plus de stress = moins de satisfaction = moins de fidélité
PIÈGE : Stress / Dépenses : r = 0.16* => significatif mais TRÈS faible, aucune pertinence managériale
Méthode complémentaire suggérée : régression linéaire multiple
Exo 3 — Régression dépenses santé USA
R² = 0.724 (72,4% variance expliquée) — F = 873, p < 0.001 => excellente qualité du modèle
Tabagisme : B = 23 836.9, β_std = 1.968 => PLUS GRANDE influence (β_std le plus élevé)
Âge : B = 273.1, p < 0.001 => significatif (chaque année = +273$ de dépenses)
Nb enfants : B = 486.2, p < 0.001 => significatif
PIÈGE : Sexe : B = 61.3, p = 0.861 => NON significatif — à ignorer dans l'interprétation
Flash Questions Types
Quelle mesure utiliser quand la distribution est asymétrique ?
La médiane — robuste aux valeurs extrêmes. La moyenne est tirée vers la queue.
Comment identifier le prédicteur le plus influent en régression ?
Comparer les β standardisés (estimation standardisée). Le plus grand en valeur absolue = plus grande influence relative.
ANOVA significative : que faire ensuite ?
Obligatoirement un test post hoc de Tukey pour identifier quels groupes diffèrent entre eux.
r = 0.16, p = 0.03 — comment interpréter ?
Significatif mais TRÈS faible. Statiquement significatif (p < 0.05) mais la corrélation est négligeable — aucune conclusion managériale pertinente.
R² = 0.724 — que signifie ce chiffre ?
Le modèle explique 72,4% de la variance de la variable dépendante. C'est un excellent pouvoir explicatif.
