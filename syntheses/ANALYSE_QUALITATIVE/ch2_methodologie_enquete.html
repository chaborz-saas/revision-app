Ch.2 — Méthodologie de l'enquête qualitative

Ce chapitre détaille les étapes de la méthodologie qualitative : choix du terrain, rédaction du guide d'entretien, réalisation des entretiens, retranscription et grille d'analyse.

Sommaire : 1. Les 5 étapes 2. Choix du terrain 3. Guide d'entretien 4. Réalisation 5. Retranscription 6. Grille d'analyse

1. Les 5 étapes de la méthodologie qualitative

Pipeline méthodologique :
1. Choix du terrain → 2. Rédaction du guide d'entretien → 3. Réalisation des entretiens → 4. Retranscription → 5. Analyse

2. Le choix du terrain

  • L'étude peut porter sur une ou plusieurs études de cas
  • La revue de littérature scientifique est la toile de fond pour structurer le guide d'entretien
  • Le sujet doit être d'actualité, avec des références récentes recommandées
Sources recommandées : ScienceDirect, EBSCO, Google Scholar, Cairn.info

3. Le guide d'entretien

Guide d'entretien = outil structuré selon la logique de l'entonnoir (du général au spécifique).

Plan type :

  1. Présentation du travail et des objectifs
  2. Présentation du sujet
  3. Objectifs de publication
  4. Questions ouvertes ou fermées
Attention : Le guide d'entretien va dans les ANNEXES du mémoire, PAS dans la méthodologie.

La revue de littérature aide à identifier les thèmes à aborder dans le guide.

4. La réalisation des entretiens

Comment contacter les personnes ?

  • Réseaux sociaux (LinkedIn…)
  • Réseau de recherche
  • Réseau professionnel
  • Entreprise d'accueil (stage, alternance)

Modalités pratiques

CritèreRecommandation
Durée idéale45 minutes (ne pas lasser l'interlocuteur)
Formats possiblesFace à face, téléphone, visio (Skype, Teams…)
EnregistrementConseillé, avec l'accord de l'interviewé
Noms citésAutorisation écrite obligatoire
Minimum exigé5 entretiens
L'enregistrement est conseillé AVEC l'accord de l'interviewé. Si les personnes sont nommées dans le travail, une autorisation écrite est obligatoire.

5. La retranscription

La transcription doit être intégrale (obligatoire).

Format standard :

Entretien n°X – Fonction – Date
Durée : XX min
Lieu : (anonymisé)
Transcripteur : Nom
  • Numéroter les lignes (utile pour le codage ultérieur)
  • Toute la démarche doit être décrite en détail dans la section « collecte des données »

6. La grille d'analyse

Les informations collectées doivent être analysées de manière thématique.

Objectif : identifier les thématiques principales + les illustrer par le codage des verbatim (extraits des entretiens).
  • Codage manuel ou avec un outil d'analyse de contenu
  • Construction d'un dictionnaire des thèmes
