Ch.3 — Codage & Analyse thématique

Ce chapitre couvre le pipeline d'analyse qualitative : du texte brut aux affirmations, en passant par le codage (ouvert, axial, sélectif), la construction de catégories et de thèmes, et la rédaction des résultats.

Sommaire : 1. Pipeline 2. Unités de sens 3. 3 niveaux de codage 4. Codage ouvert 5. Codage axial 6. Codage sélectif 7. Analyse thématique 8. Rédaction

1. Le pipeline d'analyse qualitative

Pipeline complet :
Données → Unités de sens → Codes → Catégories → Thèmes → Récit → Affirmations

2 façons de parcourir les données :

ApprocheDescriptionQuand l'utiliser
Verticale (intra-cas)Rester dans une même interview pour préserver le contexteLors du codage initial
Horizontale (inter-cas)Comparer les codes entre interviewsPour identifier significations communes ou divergentes
Principe fondamental : Privilégier la cohérence conceptuelle plutôt que l'application stricte des procédures. Éviter la « dérive positiviste ».

2. Les unités de sens

Unité de sens = le plus petit segment de texte (ou d'image) qui exprime une idée unique pertinente par rapport à la question de recherche.
  • Préserver le contexte local : lire avant et après le segment
  • Éviter de sur-découper : conserver une unité suffisamment grande pour porter son sens

3. Les 3 niveaux de codage

NiveauDescriptionObjectif
Codage ouvertDécouper les données en unités de sens, attribuer des étiquettes provisoiresRester proche des données brutes
Codage axialRelier les codes entre eux (conditions, interactions, conséquences)Former des catégories et sous-catégories
Codage sélectifIdentifier une catégorie centrale qui intègre les autresProduire un récit cohérent (storyline)

4. Règles pratiques de codage ouvert

  • Coder ce qui est dit (sémantique) ET/OU ce qui est implicite (latent)
  • Noms de codes courts et descriptifs — les verbes aident : « gérer le risque », « rejeter la faute »
  • Autoriser les codes qui se chevauchent, pas de hiérarchie trop tôt
  • Segments incertains → liste « à vérifier » (ne pas les ignorer !)
Codebook léger : nom du code + définition courte + 2-3 citations exemplaires

5. Des codes aux catégories (codage axial)

Regrouper les codes qui co-existent ou partagent des conditions / conséquences.

Pour chaque catégorie, répondre à :

  1. Idée centrale — quel concept unifie ces codes ?
  2. Étendue — où ça ne s'applique pas ?
  3. Relations — liens avec d'autres catégories ?
Bonnes catégories = conceptuellement claires (1 seule idée) + analytiquement utiles (expliquent quelque chose) + distinctes mais liées.
Test de validité : résumer la catégorie en 2-3 phrases sans lister les codes. Si ce n'est pas possible, continuer à fusionner ou scinder.

6. Codage sélectif et intégration

  1. Choisir UNE catégorie centrale qui explique le mieux le phénomène étudié
  2. Relier les autres catégories à cette catégorie centrale
  3. Esquisser un récit d'une page avec 2-3 extraits par catégorie

7. L'analyse thématique réflexive

Un thème ≠ simple catégorie de sujet. Un thème capture un sens partagé unifié par un concept organisateur central.

Options de structuration : thèmes, sous-thèmes, thème global.

Ne pas ajouter des couches (sous-thèmes, sous-sous-thèmes…) au détriment de la profondeur analytique.

8. La rédaction des résultats

  • Raconter une histoire cohérente tout en respectant la complexité
  • Montrer la traçabilité : données → codes → thèmes → affirmations
  • Équilibrer description et interprétation
Structure d'un article / mémoire :
Abstract → Introduction → Revue de littérature → Méthodologie → Résultats → Discussion → Conclusion → Annexes
