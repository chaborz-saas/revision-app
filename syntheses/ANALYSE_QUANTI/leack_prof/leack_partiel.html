1. Les quatre grandes familles de variables

Variable qualitative nominale : Catégories sans ordre naturel. Exemples : Genre (homme/femme), secteur d'activité, région géographique.
Variable qualitative ordinale : Catégories avec un ordre logique mais sans intervalle mesurable. Exemple : Niveau de satisfaction (faible – moyen – fort).
Variable quantitative discrète : Valeurs numériques entières, dénombrables. Exemple : Nombre de commandes (0, 1, 2, 3…).
Variable quantitative continue : Valeurs numériques réelles pouvant prendre n'importe quelle valeur dans un intervalle. Exemples : Salaire (€), montant d'achat (€), âge (années).
Point critique : Le type de variable conditionne entièrement le choix du test statistique. Identifier correctement les variables avant tout calcul est une étape fondamentale.
Type de variable Caractéristiques Exemples Tests adaptés
Qualitative nominale Catégories sans ordre Genre, région, secteur Khi-deux, V de Cramér
Qualitative ordinale Catégories ordonnées Satisfaction (faible/moyen/fort) Khi-deux, Spearman
Quantitative discrète Entiers dénombrables Nombre de commandes Pearson, t-test, ANOVA
Quantitative continue Valeurs réelles Salaire, CA, âge Pearson, t-test, ANOVA, Régression

2. Les indicateurs de tendance centrale

Moyenne : Somme de toutes les valeurs divisée par le nombre d'observations. Représente le "centre de gravité" de la distribution.
Moyenne (x̄) = (Σ xᵢ) / n
Exemple : Salaire moyen = 2 450 €
Médiane : Valeur qui divise la distribution en deux moitiés égales : 50 % des observations sont en dessous, 50 % au-dessus. Moins sensible aux valeurs extrêmes que la moyenne.
Médiane = valeur centrale (ou moyenne des deux valeurs centrales si n est pair)
Exemple : Médiane du CA = 120 000 €
Mode : Valeur (ou modalité) qui apparaît le plus fréquemment dans la distribution.
Exemple : Catégorie la plus vendue = café.
Règle d'or : Si la distribution est parfaitement symétrique, alors Moyenne = Médiane = Mode.
En cas de valeurs extrêmes (outliers) : la médiane est plus robuste et représentative que la moyenne, qui est tirée vers les valeurs aberrantes.

3. Les indicateurs de dispersion

Étendue : Différence entre la valeur maximale et la valeur minimale. Mesure simple mais très sensible aux extrêmes.
Étendue = Max − Min
Exemple : Âge des clients → 65 − 18 = 47 ans
Variance (σ²) : Moyenne des carrés des écarts à la moyenne. Quantifie l'écart moyen au carré.
σ² = (Σ (xᵢ − x̄)²) / n
Exemple : σ² = 4 900
Écart-type (σ) : Racine carrée de la variance. Exprimé dans la même unité que la variable, il mesure la dispersion moyenne autour de la moyenne.
σ = √σ²
Exemple : σ = 70 (dans l'unité de la variable)
Coefficient de variation (CV) : Dispersion relative, exprimée en pourcentage. Permet de comparer la dispersion entre des variables d'unités différentes.
CV = (σ / x̄) × 100
Exemple : CV = 15 % — dispersion modérée par rapport à la moyenne
Interprétation managériale : Une forte dispersion signale une hétérogénéité au sein du groupe. C'est un signal d'exploration : pourquoi certains individus se comportent-ils très différemment de la moyenne ?

4. Visualiser les données

Choix du graphique selon le type de variable

Graphique Type de variable Usage principal
Histogramme (densité) Quantitative continue Observer la forme de la distribution
Diagramme en barres Qualitative (nominale ou ordinale) Comparer des fréquences par catégorie
Boxplot (boîte à moustaches) Quantitative continue Comparer des groupes, détecter les outliers

Interpréter un histogramme

Distribution symétrique (en cloche) : Les données sont équilibrées de part et d'autre de la moyenne. La moyenne, la médiane et le mode coïncident. Forme idéale pour la plupart des tests paramétriques.
Asymétrie à droite (positive) : La queue s'étend vers la droite. La majorité des valeurs est concentrée à gauche (valeurs faibles), quelques valeurs très élevées tirent la distribution. La moyenne > médiane.
Asymétrie à gauche (négative) : La queue s'étend vers la gauche. La majorité des valeurs est concentrée à droite (valeurs élevées), quelques valeurs très faibles tirent la distribution. La moyenne < médiane.

Le Boxplot (boîte à moustaches)

Composition du boxplot :
  • Q1 : 1er quartile (25e percentile) — 25 % des données sont en dessous
  • Médiane : 2e quartile (50e percentile) — trait central de la boîte
  • Q3 : 3e quartile (75e percentile) — 75 % des données sont en dessous
  • IQR (Écart interquartile) = Q3 − Q1 — longueur de la boîte
  • Moustaches : s'étendent jusqu'à Q1 − 1,5 × IQR (bas) et Q3 + 1,5 × IQR (haut)
  • Valeurs aberrantes (outliers) : points au-delà des moustaches
IQR = Q3 − Q1
Borne inférieure moustache = Q1 − 1,5 × IQR
Borne supérieure moustache = Q3 + 1,5 × IQR
Lecture de la symétrie sur un boxplot : Si la médiane est centrée dans la boîte → distribution symétrique. Si la médiane est proche de Q1 → asymétrie à droite. Si la médiane est proche de Q3 → asymétrie à gauche.

6. Test du Khi-deux — Association entre deux variables qualitatives

Objectif : Tester s'il existe une association statistique entre deux variables qualitatives (nominales ou ordinales). Compare les fréquences observées aux fréquences attendues sous l'hypothèse d'indépendance.
H₀ : Il n'y a pas d'association entre les deux variables (indépendance)
H₁ : Il existe une association entre les deux variables

Règle de décision : Si p ≤ 0,05 → rejeter H₀ → association statistiquement significative
V de Cramér : Mesure la force (intensité) de l'association, indépendamment de la taille de l'échantillon. Compris entre 0 (aucune association) et 1 (association parfaite).
Exemple du cours : χ² = 47,6, ddl = 14, p < 0,001
Interprétation : p < 0,05 donc H₀ rejetée. L'association entre les deux variables qualitatives est statistiquement significative.

7. Corrélation de Pearson — Relation entre deux variables quantitatives

Coefficient r de Pearson : Mesure la force et la direction d'une relation linéaire entre deux variables quantitatives continues. Compris entre −1 et +1.
H₀ : r = 0 (pas de corrélation linéaire)
H₁ : r ≠ 0 (il existe une corrélation)

Règle de décision : Si p ≤ 0,05 → corrélation statistiquement significative

Direction : r > 0 → corrélation positive (les deux variables augmentent ensemble)
r < 0 → corrélation négative (une augmente, l'autre diminue)

Barème d'intensité de la corrélation

Valeur absolue |r| Intensité de la corrélation
0,00 – 0,20 Très faible (négligeable en pratique)
0,20 – 0,40 Faible
0,40 – 0,60 Modérée
0,60 – 0,80 Forte
0,80 – 1,00 Très forte
Attention : Une corrélation statistiquement significative (p ≤ 0,05) ne signifie pas nécessairement une corrélation forte. Avec un grand échantillon, même un r très faible peut être significatif. Il faut toujours interpréter la taille de l'effet (valeur de |r|), pas seulement le p-value.
Exemple matrice (cours) :
  • Engagement vs Dépenses : r = 0,68** → forte corrélation positive significative
  • Utilisation vs Dépenses : r = 0,62** → forte corrélation positive significative
  • Satisfaction vs Engagement : r = 0,63** → forte corrélation positive significative
(** = significatif au seuil 0,01)

8. Test t de Student — Comparaison de deux moyennes

Objectif : Comparer les moyennes d'une variable quantitative entre deux groupes définis par une variable qualitative à deux modalités (ex : homme vs femme, fumeur vs non-fumeur).
H₀ : Moyenne groupe 1 = Moyenne groupe 2 (pas de différence)
H₁ : Moyenne groupe 1 ≠ Moyenne groupe 2 (il y a une différence)

Règle de décision : Si p ≤ 0,05 → différence statistiquement significative entre les deux groupes
Rappel : Le test t est le cas particulier de l'ANOVA à deux groupes. Pour 3 groupes ou plus, on utilise l'ANOVA.

9. ANOVA — Comparaison de 3 moyennes ou plus

ANOVA (Analyse de Variance) : Permet de comparer simultanément les moyennes d'une variable quantitative pour 3 groupes ou plus, définis par une variable qualitative. Elle teste si au moins une moyenne diffère des autres.
H₀ : Toutes les moyennes des groupes sont égales (μ₁ = μ₂ = μ₃ = …)
H₁ : Au moins une moyenne diffère

Règle de décision : Si p ≤ 0,05 → différence statistiquement significative (mais on ne sait pas encore laquelle)

Choix entre Fisher et Welch

Test de Levene : Préalable à l'ANOVA, il vérifie l'homogénéité des variances entre les groupes.
  • Si p (Levene) > 0,05 → variances homogènes → utiliser le test de Fisher (ANOVA classique)
  • Si p (Levene) ≤ 0,05 → variances non homogènes → utiliser le test de Welch (ANOVA robuste)

Test post hoc de Tukey

Test de Tukey : Après une ANOVA significative, le test de Tukey permet d'identifier précisément quelles paires de groupes diffèrent significativement l'une de l'autre. Il réalise des comparaisons multiples entre chaque combinaison de groupes.
Distinction fondamentale :
  • ANOVA → répond à : "Est-ce qu'au moins une moyenne diffère ?" (oui/non)
  • Tukey → répond à : "Quels groupes spécifiques diffèrent ?" (identification des paires)
L'ANOVA sans Tukey ne permet pas de savoir quels groupes sont différents.

10. Régression linéaire multiple

Objectif : Modéliser et prédire une variable quantitative continue (variable dépendante Y) à partir de plusieurs prédicteurs (variables indépendantes X₁, X₂, … Xₙ), qui peuvent être quantitatifs ou qualitatifs (variables dummy).
Modèle : Y = β₀ + β₁X₁ + β₂X₂ + … + βₙXₙ + ε

Où : β₀ = constante (intercept)
βᵢ = coefficient de régression de Xᵢ
ε = terme d'erreur résiduel

Interpréter les coefficients

Coefficient B (non standardisé) : Variation de Y pour une augmentation d'une unité de Xᵢ, toutes autres variables constantes. Interprétable dans l'unité de la variable.

Coefficient β standardisé (bêta_std) : Coefficient exprimé en écarts-types. Permet de comparer l'importance relative des prédicteurs entre eux, indépendamment des unités. Plus |β_std| est élevé, plus la variable a d'influence relative.

Indicateurs de qualité du modèle

Indicateur Signification Règle d'interprétation
R² % de variance de Y expliquée par le modèle Plus R² est proche de 1, mieux le modèle ajuste les données
R² ajusté R² corrigé pour le nombre de prédicteurs Préférer le R² ajusté pour comparer des modèles avec ≠ prédicteurs
Statistique F Test de significativité globale du modèle Si p < 0,05 : le modèle est globalement significatif
p-value de chaque βᵢ Significativité de chaque prédicteur Si p < 0,05 : le prédicteur contribue significativement
Test F global :
H₀ : Tous les coefficients βᵢ = 0 (le modèle n'explique rien)
H₁ : Au moins un coefficient βᵢ ≠ 0 (le modèle est utile)
Si p < 0,05 → modèle globalement significatif

Variables qualitatives dans la régression (dummy variables)

Variable dummy (indicatrice) : Une variable qualitative à k modalités est recodée en k−1 variables binaires (0/1) pour entrer dans la régression. La modalité exclue constitue la référence.
Le coefficient associé mesure l'écart de moyenne par rapport à la catégorie de référence.
Exemple (cours) : Genre Homme (réf. = Femme) : B = −3,64, p = 0,016
Interprétation : Toutes choses égales par ailleurs, les hommes dépensent en moyenne 3,64 € de moins que les femmes.
Modèle 1 — Montant = f(Visites, Satisfaction) :
  • Visites : B = 2,99, p < 0,001, β_std = 0,508 → forte influence, significatif
  • Satisfaction : B = 3,46, p < 0,001, β_std = 0,256 → influence modérée, significatif
Les visites ont l'impact le plus élevé (β_std le plus grand).

Modèle 2 — Montant = f(Visites, Satisfaction, Genre) :
  • Genre Homme/Femme : B = −3,64, p = 0,016, β_std = −0,291 → significatif, référence = Femme

11. Correction du Partiel 2025/2026 — Track Anglo (FeelWell & USA Health)

Exercice 1 (3 pts) — Histogramme de satisfaction FeelWell (480 utilisateurs, échelle 1–10)

Contexte : Analyse de la distribution des scores de satisfaction de 480 utilisateurs de l'application FeelWell.
Q1 — Description de l'histogramme :
Distribution unimodale (un seul pic), pic observé entre 5 et 6, forme globalement symétrique, dispersion modérée (valeurs concentrées entre 4 et 7).
Q2 — Relation Moyenne / Médiane / Mode :
La distribution est approximativement symétrique, donc : Moyenne ≈ Médiane ≈ Mode.
Dans une distribution parfaitement symétrique, les trois indicateurs de tendance centrale coïncident.
Q3 — Quel indicateur est le plus représentatif ?
La moyenne est sensible aux valeurs extrêmes. Par exemple, si un petit groupe d'utilisateurs donne des notes très faibles (1–2), ces valeurs aberrantes tirent la moyenne vers le bas alors que la majorité des utilisateurs est satisfaite. Dans ce cas, la médiane reste plus représentative car elle n'est pas affectée par les valeurs extrêmes.

Exercice 2 (8 pts) — Matrice de corrélation FeelWell (480 utilisateurs)

Variables analysées (toutes quantitatives continues) : Utilisation (heures/semaine), Engagement (score 0–100), Stress (score 1–10), Satisfaction (score 1–10), Dépenses (€/mois).

Matrice de corrélation de Pearson

Variables Utilisation Engagement Stress Satisfaction Dépenses
Utilisation 1 — — — —
Engagement 0,66** 1 — — —
Stress 0,29** 0,41** 1 — —
Satisfaction 0,51** 0,63** −0,39** 1 —
Dépenses 0,62** 0,68** 0,16* 0,55** 1

** p < 0,01 (significatif au seuil 1 %)  |  * p < 0,05 (significatif au seuil 5 %)

Q1 — Quel test utiliser ?
Le test de corrélation de Pearson, car toutes les variables sont quantitatives continues.
Q2 — Les 3 relations les plus fortes :
  1. Engagement ↔ Dépenses : r = 0,68**, p < 0,001 → forte corrélation positive significative. Les utilisateurs les plus engagés dépensent davantage (abonnements premium, achats in-app).
  2. Utilisation ↔ Dépenses : r = 0,62**, p < 0,001 → forte corrélation positive significative. Plus un utilisateur passe du temps sur l'app, plus il dépense.
  3. Satisfaction ↔ Engagement : r = 0,63**, p < 0,001 → forte corrélation positive significative. Les utilisateurs satisfaits sont plus engagés, ce qui renforce la fidélité.
Q3 — Relation trompeuse : Stress ↔ Dépenses (r = 0,16, p < 0,05)
Cette corrélation est statistiquement significative mais d'intensité très faible (|r| = 0,16). L'effet pratique est négligeable. L'erreur serait de conclure que le stress génère des dépenses : la significativité statistique ne garantit pas la pertinence managériale. Avec 480 observations, même de très faibles effets deviennent significatifs.
Q4 — Relation négative : Stress ↔ Satisfaction (r = −0,39)
Corrélation négative modérée significative : plus le niveau de stress est élevé, moins l'utilisateur est satisfait. D'un point de vue managérial, réduire le stress des utilisateurs est un levier direct d'amélioration de la satisfaction et donc de la fidélité.
Q5 — Recommandations managériales :
  • Renforcer l'engagement des utilisateurs (notifications, gamification, contenus personnalisés)
  • Encourager l'utilisation régulière de l'application
  • Réduire le stress perçu (fonctionnalités de relaxation, méditation)
  • Ne pas investir dans des actions liées au stress pour stimuler les dépenses (relation trop faible)
Q6 — Méthode complémentaire :
Régression linéaire multiple. Variable dépendante (VD) = Dépenses (€). Variables indépendantes = Utilisation, Engagement, Stress, Satisfaction. Cette méthode permet d'identifier la contribution propre (toutes choses égales par ailleurs) de chaque variable sur les dépenses, et de contrôler les effets de confusion.

Exercice 3 (9 pts) — Régression linéaire multiple — Dépenses santé (USA)

Contexte : Modélisation des dépenses de santé annuelles aux États-Unis. Variable dépendante : Dépenses de santé (€/an). Prédicteurs : Âge (années), Statut tabagique (fumeur/non-fumeur), Nombre d'enfants, Sexe (masculin/féminin).

Résultats globaux du modèle

Indicateur Valeur Interprétation
R (corrélation multiple) 0,851 Très forte corrélation entre prédicteurs et VD
R² (coefficient de détermination) 0,724 72,4 % de la variance des dépenses expliquée
R² ajusté 0,723 Très proche de R² → modèle parcimonieux, bon ajustement
Statistique F 873 Très élevée → modèle globalement très significatif
p-value (modèle) < 0,001 Le modèle est globalement significatif (p < 0,05)

Coefficients des prédicteurs

Prédicteur B (non standardisé) β standardisé p-value Significatif ?
Âge (années) 273,1 0,317 < 0,001 Oui
Tabagisme (Fumeur vs Non-fumeur) 23 836,9 1,968 < 0,001 Oui — impact MAJEUR
Nombre d'enfants 486,2 0,048 < 0,001 Oui — mais faible effet
Sexe (Masculin vs Féminin) 61,3 — 0,861 Non (p > 0,05)
Q1 — Quel test utiliser ?
La régression linéaire multiple, car la variable dépendante (dépenses de santé) est quantitative continue, et les prédicteurs sont de nature mixte (variables quantitatives continues + variables qualitatives recodées en dummy).
Q2 — Prédicteurs significatifs et non significatifs :
  • Significatifs (p < 0,05) : Âge, Tabagisme (Fumeur), Nombre d'enfants
  • Non significatif (p = 0,861 > 0,05) : Sexe (Masculin)
Le sexe ne contribue pas significativement à expliquer les dépenses de santé, toutes choses égales par ailleurs.
Q3 — Variable avec le plus d'influence :
Le Tabagisme (statut Fumeur) avec β_std = 1,968 — de loin le coefficient standardisé le plus élevé.
Interprétation : Être fumeur est associé à des dépenses de santé supérieures de 23 836,9 € par an, toutes choses égales par ailleurs. C'est le facteur de loin le plus déterminant du modèle.
Q4 — Qualité du modèle :
La qualité est très élevée :
  • R² = 0,724 : le modèle explique 72,4 % de la variance des dépenses de santé — excellent pouvoir explicatif.
  • R² ajusté ≈ R² (0,723) : le modèle n'est pas surajusté, il est parcimonieux.
  • F = 873, p < 0,001 : le modèle est globalement très significatif.
Q5 — Recommandations managériales :
  • Priorité absolue : Programmes anti-tabac — le tabagisme explique à lui seul l'essentiel de l'impact sur les dépenses.
  • Adapter les offres d'assurance selon l'âge (segmentation tarifaire par tranche d'âge).
  • Tenir compte du nombre d'enfants dans les offres familiales.
  • Ne pas intégrer le sexe comme critère discriminant — il n'a aucun effet significatif sur les dépenses.
Q6 — Variables supplémentaires à intégrer dans un modèle enrichi :
  • Niveau de revenu (les dépenses de santé sont corrélées au revenu)
  • Présence de maladies chroniques (diabète, hypertension, etc.)
  • Couverture d'assurance santé (franchise, type de plan)
  • Indice de masse corporelle (IMC)
  • Région géographique (disparités de coûts médicaux selon les États)
Récapitulatif — Points à ne pas confondre à l'examen :
  • p < 0,05 = statistiquement significatif ≠ fort ou important en pratique
  • r faible et p significatif = corrélation réelle mais négligeable sur le plan pratique
  • ANOVA → dit SI une différence existe / Tukey → dit LAQUELLE
  • R² → qualité du modèle (% variance expliquée) / β_std → importance relative des prédicteurs
  • Médiane → robuste aux outliers / Moyenne → sensible aux valeurs extrêmes
  • Corrélation ≠ Causalité : une corrélation forte ne prouve pas un lien de cause à effet
